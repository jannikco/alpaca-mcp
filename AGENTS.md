# Alpaca MCP setup and connection checker

Start with capabilities.json and `.agents/skills/heymyapps-alpaca/SKILL.md` (legacy installs may use `pipmcp-alpaca`). This package uses the private HeyMyApps gateway. Live discovery/execution requires `HEYMYAPPS_API_KEY` (or the `PIPMCP_API_KEY` alias); no provider runtime or credential mapper is bundled. Actual hosted schemas, selected connections and permissions are authoritative. Run `npm test`; default `npm start` is offline. Never claim fixture tests prove live provider access.
