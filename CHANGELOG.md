# Changelog

## 1.0.1

Rebrand documentation and client defaults from PipMCP to HeyMyApps (heymyapps.com). Gateway origin is `https://heymyapps.com/api/v1`; `HEYMYAPPS_*` env vars are primary with `PIPMCP_*` aliases. Adds `HeyMyAppsGatewayClient`, the `heymyapps-alpaca` skill and clarifies that published Alpaca trading tools (for example `create_order`) can place real orders.

## 1.0.0

Authenticated private execution, actual schema discovery, durable receipts, task skills and one API key. Historical local runtimes remain in Git history.
